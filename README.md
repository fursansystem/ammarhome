# Ammar Home - موقع بورتفوليو

موقع ثابت (Static) باللغة العربية ويدعم اتجاه RTL. لا يحتاج إلى بناء. افتح الملف `index.html` مباشرة.

## تشغيل ومعاينة
- **فتح مباشر:** انقر مرتين على `index.html` وسيُفتح في المتصفح.
- **خادم محلي (اختياري):** لتجربة أفضل على الروابط والتنقل السلس:
  - Python: `python -m http.server 8080`
  - ثم افتح: http://localhost:8080/

## البنية
- `index.html`: الصفحة الرئيسية مع الأقسام الرئيسية.
- `assets/js/main.js`: سكربت بسيط للقائمة الجوال والتنقل السلس ورسالة نموذج التواصل.

## التخصيص السريع
- **الهوية البصرية:** حدِّث الألوان من داخل `index.html` في كائن Tailwind تحت `colors.brand`.
- **الشعار:** استبدل العنصر الدائري في الهيدر بصورة شعارك أو ارفع ملف الشعار وأضف `<img>` مكانه.
- **المحتوى:** عدّل النصوص وأرقام التواصل والبريد داخل الأقسام:
  - قسم من نحن: `#about`
  - الخدمات: `#services`
  - الأعمال: `#projects`
  - الآراء: `#testimonials`
  - التواصل: `#contact`
- **الصور:** استبدل روابط Unsplash بصورك.

## نموذج التواصل (اختياري)
لإرسال النموذج إلى بريدك دون Backend يمكنك استخدام خدمة Formspree أو Getform:
1) أنشئ نموذجًا واحصل على رابط `action`.
2) استبدل `onsubmit="return false;"` في `<form>` بـ `action="FORM_ENDPOINT" method="POST"`.
3) أضف حقول `name` للمدخلات حتى تُرسل بشكل صحيح.

مثال:
```html
<form action="https://formspree.io/f/xxxxxx" method="POST">
  <input name="name" />
  <input name="phone" />
  <input type="email" name="email" />
  <textarea name="message"></textarea>
  <button type="submit">إرسال</button>
</form>
```
